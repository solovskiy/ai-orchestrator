# Резюме README.md — .ai: оркестрация CLI-агентов

## Что это
Инструментарий для делегирования задач кодовым AI-агентам. Claude Code выступает оркестратором, исполнители — внешние CLI (сейчас `opencode`). Директория самодостаточна, не содержит внешних путей, может быть скопирована целиком.

**Требования:** Git Bash, Node, opencode в PATH.

## Основные команды

| Команда | Назначение |
|---|---|
| `delegate` | **Рекомендуемый вход**: start + wait + heal + result одним вызовом |
| `start` | Запустить задачу в фоне (возвращает управление сразу) |
| `chat` | Интерактивный чат с моделью в терминале (foreground) |
| `send <id> "<текст>"` | Продолжить сессию новой задачей |
| `list` | Таблица всех задач |
| `stats [--days N] [--json]` | Агрегация стоимости и токенов |
| `status <id>` | Детали задачи; при провале — хвост verify.log |
| `tail <id> [n]` | Последние строки вывода агента |
| `wait <id>...` | Ждать завершения задач |
| `result <id>` | Только итоговый ответ |
| `kill <id>` | Остановить задачу |
| `heal <id>` | Автовосстановление проваленной задачи |
| `worktree-gc` | Уборка worktree-веток (dry-run без --apply) |
| `clean [--days N]` | Убрать задачи старше N дней |
| `remember/recall/forget/learn` | Долговременная память |
| `dashboard` | Локальный веб-интерфейс (localhost:9191) |

## Ключевые концепции

- **Capability / Agent** — предопределённые профили (coding, research) с model, worktree, variant, permissions
- **Мультимодельность** — поддержка opencode, deepseek, openai, anthropic (claude/gemini/codex — experimental)
- **Авто-коммит** — в worktree коммитит изменения автоматически, если модель забыла
- **Диагностика провалов** — diagnosis.json с outcome, toolCalls, lastErrorMessage

## Написание ТЗ (важно)

1. **Пути только относительные** — модель не должна строить абсолютные пути к основному репозиторию
2. **Всё, на что ссылается ТЗ, должно быть закоммичено** в base ref
3. **Требовать явно:** не сдаваться молча на первой ошибке
4. **После `verify: passed` всегда проверять `git diff --stat`** — пустой дифф при passed означает, что агент ничего не сделал
