## 1. Правила чтения отчёта

### 1.1 Маппинг лидерборд-имён → provider ID

LMArena публикует модели под собственными именами, где reasoning-variant часто
приклеен к имени. В наших рекомендациях **variant всегда отдельное поле**, ID —
только из списка провайдера:

|---|---|---|---|
| `kimi-k3-max` | `opencode-go/kimi-k3` | `max` | единственный вариант kimi-k3 |
| `glm-5.2-max` | `opencode-go/glm-5.2` | `max` | |
| `deepseek-v4-flash-high`, `deepseek-v4-flash-high-preview` | `opencode-go/deepseek-v4-flash` | `high` | |
| `deepseek-v4-pro-high-preview` | `opencode-go/deepseek-v4-pro` | `high` | |

| `qwen3.7-max-preview`, `qwen3.7-max-20260517` | `opencode-go/qwen3.7-max` | high/max | **экстраполяция**: preview-записи LMArena переносим на нашу модель с пометкой |
| `qwen3.8-max`, `kimi-k2.6`, `hy3`, `mimo-v2.5(-pro)`, `minimax-m2.7`, `minimax-m3`, `qwen3.6-plus`, `qwen3.7-plus`, `glm-5.1`, `grok-4.5` | тот же ID | — | прямое совпадение |

`minimax-m2.5` присутствует в LMArena и SWE-bench, но **в нашем провайдере её нет** —
из кандидатов исключена (в v1 ошибочно упоминалась).

### 1.2 Цены

Цены в таблицах — **из списка провайдера** (достоверные). LMArena показывает цены
чуть иначе (hy3 $0.13/$0.53, qwen3.7-plus $0.32/$1.28, kimi-k2.7-code $0.73/$3.50,
minimax-m3 $0.60/$2.40 = тариф выше 512K) — эти расхождения игнорируем, считаем по
нашим ценам.

### 1.3 Preliminary

`*` в таблице = статус «Preliminary» на LMArena: мало голосов, широкий доверительный
интервал. Ключевые случаи: qwen3.8-max (Overall 3 327 голосов, CW вообще 603),
kimi-k3-max (3 556 / 597), qwen3.7-max-preview (3 695 / 479), deepseek-v4-flash-high
в WebDev (1 319), hy3 (WebDev 1 491, Coding 976). Такие ранги — сильный сигнал, но
не приговор; для дорогих решений желателен A/B на наших задачах.

### 1.4 Что исправлено относительно v1

1. Не используются несуществующие ID (`kimi-k3-max`, `glm-5.2-max`,
   `deepseek-v4-flash-high` как ID) — это пары «базовый ID + variant».
2. `qwen3.7-max` **заявлен в нашем провайдере** (v1 писала обратное). Данные по нему —
   экстраполяция с LMArena-preview записей.
3. `mimo-v2.5-pro` присутствует во всех таблицах, где релевантна (в v1 пропущена в
   таблице роли research-code).
4. `minimax-m2.5` не упоминается как кандидат — её нет у провайдера.
5. Одна общая таблица вместо подтаблиц по разделам — исключает рассинхронизацию.
