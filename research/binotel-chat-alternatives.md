# Аналоги Binotel Chat с открытым исходным кодом (чат на сайте + Telegram)

> **Дата исследования:** 2026-07-28  
> **Цель:** Найти open-source решение онлайн-чата на сайт, где рабочая область оператора находится в Telegram, с поддержкой топиков/комнат под каждый чат.

---

## Ключевые требования

| Функция | Описание |
|---------|----------|
| 🧩 **Open source** | Полностью открытый исходный код, возможность самостоятельного хостинга |
| 💬 **Рабочее место оператора в Telegram** | Ответы на сообщения приходят и отправляются прямо из Telegram |
| 🏠 **Комнаты/топики** | Каждый новый чат с посетителем создаёт отдельную тему (topic) в группе Telegram |
| ⚡ **Быстрые ответы / шаблоны** | Заранее заготовленные ответы для типовых ситуаций |
| 📝 **Форма обратной связи** | Сбор имени/email перед началом чата |
| 🤖 **Автоматические сообщения** | Приветствие, автоответ при первом сообщении |
| 🔄 **Автоответы** | Ответы по ключевым словам, AI-автоответчик |
| ⏰ **Рабочее время** | Отображение статуса "офлайн" и сбор сообщений вне работы |

---

## 📊 Сравнение решений

### 1. 🌟 Site Chat on Telegram (WordPress плагин) — **ЛУЧШИЙ ВАРИАНТ**

| Характеристика | Значение |
|----------------|----------|
| **Ссылка** | https://wordpress.org/plugins/site-chat-on-telegram/ |
| **Лицензия** | Open Source (GPL) |
| **Статус** | Активно развивается (последнее обновление фев 2026) |
| **Платформа** | WordPress |
| **Установок** | 100+ |

**Функции:**
- ✅ Автоответы по ключевым словам
- ✅ AI-интеграция с OpenAI (кастомный system prompt)
- ✅ Автоматический ответ на первое сообщение
- ✅ Рабочее время (working hours)
- ✅ Кастомизация виджета (цвета, аватар, приветствие)
- ✅ **Топики в Telegram Supergroup** — каждый чат = отдельный топик
- ✅ SEO-контроль (на каких страницах показывать)
- ✅ История сообщений в БД WordPress
- ✅ AI-переключение: может ответить сам или передать человеку
- ✅ Простая настройка через @BotFather

**Как работает:**
1. Создаёте бота через @BotFather
2. Создаёте группу в Telegram, включаете "Topics"
3. Добавляете бота админом с правами управления топиками
4. Плагин создаёт отдельный топик на каждого нового посетителя
5. Операторы отвечают прямо из Telegram — каждый чат в своём топике

**Минусы:**
- Только для WordPress
- Небольшое сообщество
- Есть баги (см. отзывы)
- Нет встроенных шаблонов/быстрых ответов (но есть автоответы по ключам)

### 2. 🌟 OuterCom — **ИДЕАЛЬНАЯ АРХИТЕКТУРА (самописный вариант)**

| Характеристика | Значение |
|----------------|----------|
| **Ссылка** | https://github.com/freewaretools/outercom |
| **Лицензия** | MIT |
| **Статус** | Production-ready, но очень новый (0 звёзд) |
| **Стек** | TypeScript, Next.js, React |

**Функции:**
- ✅ **Topic-per-customer** — каждая переписка = отдельный топик в Telegram Forum
- ✅ AI first-line (Claude Haiku 4.5 или локальная LLM через OpenAI API)
- ✅ Pre-chat form (сбор имени + email)
- ✅ Шаблоны ответов (agent names, canned responses)
- ✅ Transcript email (отправка стенограммы на почту)
- ✅ Авто-возобновление AI если оператор не ответил за N минут
- ✅ Self-healing — если топик удалили, воссоздаётся автоматически
- ✅ Notification sounds, mute toggle
- ✅ Reset/abandon — закрытие чата
- ✅ Работает без базы данных (Dev), в продакшене — Postgres
- ✅ Pluggable transport (можно переключить на Slack/Discord)

**Как работает:**
```
Посетитель → ChatWidget → /api/chat → ChatEngine → AIProvider (первая линия)
                                                      → TelegramTransport (топик)
Посетитель ← poll/api/chat ← ChatStorage ← webhook Telegram (ответ оператора)
```

**Архитектура — это именно то, что вы описали:**
- Виджет на сайте
- Каждый новый чат = новый топик в Telegram-группе (форуме)
- AI отвечает автоматически из базы знаний
- Если AI не справляется — эскалация оператору
- Оператор отвечает в топике Telegram

**Минусы:**
- Требует Next.js (App Router)
- Нужен DevOps-опыт для деплоя
- Очень свежий проект (нужно дорабатывать самому)
- Нет готовой админки

### 3. Intergram — **ПРОСТОЙ ВАРИАНТ (базовый)**

| Характеристика | Значение |
|----------------|----------|
| **Ссылка** | https://github.com/idoco/intergram |
| **Лицензия** | MPL-2.0 |
| **Звёзды** | 1,400 ★ |
| **Форки** | 365 |

**Функции:**
- ✅ Легковесный (5KB gzip)
- ✅ Self-hosted или облачный вариант
- ✅ autoResponse — автоответ при первом сообщении
- ✅ autoNoResponse — автоответ если оператор не ответил за 1 мин
- ✅ Кастомизация цветов, текстов
- ✅ Поддержка Preact/React

**Минусы:**
- ❌ **Нет топиков** — все сообщения в один чат (можно отвечать reply, но неудобно при нескольких посетителях)
- ❌ Нет разделения на комнаты
- ❌ Нет автоответов по ключевым словам
- ❌ Нет команды операторов
- ❌ Нет AI-интеграции
- Проект не очень активно развивается

### 4. Chatwoot — **ПОЛНОЦЕННАЯ CRM (но НЕ через Telegram как рабочее место)**

| Характеристика | Значение |
|----------------|----------|
| **Ссылка** | https://github.com/chatwoot/chatwoot |
| **Лицензия** | MIT |
| **Звёзды** | 34,100 ★ |
| **Статус** | Очень активный |

**Функции:**
- ✅ Live chat widget
- ✅ Telegram интеграция (можно подключить канал)
- ✅ Автоответы, AI (Captain AI)
- ✅ База знаний / Help Center
- ✅ Шаблоны ответов (canned responses)
- ✅ Формы обратной связи
- ✅ Мощная аналитика
- ✅ Omnichannel (WhatsApp, Telegram, Email, соцсети)

**Минусы:**
- ❌ **Рабочее место — собственный дашборд, НЕ Telegram**
- Telegram — лишь один из каналов, но отвечать нужно в интерфейсе Chatwoot
- Тяжёлый (Ruby on Rails, требует ресурсов)
- Сложный деплой

**Если нужно именно полноценное CRM с чатом — Chatwoot лучший open-source вариант. Но это НЕ "оператор в Telegram".**

## 🏆 Итоговые рекомендации

### Вариант 1 (если сайт на WordPress) — **Site Chat on Telegram**

Это самый простой и быстрый путь получить именно то, что вы хотите:

| Ваше требование | Как реализовано |
|----------------|-----------------|
| 🧩 Open source | ✅ GPL-лицензия, полный доступ к коду |
| 💬 Оператор в Telegram | ✅ Все уведомления и ответы — в Telegram |
| 🏠 Комнаты/топики | ✅ Каждый чат = топик в Telegram Supergroup |
| ⚡ Быстрые ответы | ✅ Автоответы по ключевым словам |
| 📝 Форма обратной связи | ✅ Сбор имени/email |
| 🤖 Автоматы | ✅ Приветствие, AI-ответы через OpenAI |
| 🔄 Автоответы | ✅ По ключевым словам + AI |
| ⏰ Рабочее время | ✅ Встроено |

**Как настроить (5 шагов):**
1. Установить плагин в WordPress
2. Создать бота через @BotFather
3. Создать Telegram-группу, включить Topics
4. Добавить бота админом с правами Manage Topics
5. Настроить плагин (бот, группа, внешний вид)

[Подробная инструкция](https://wp-guruteam.com/scot/documentation/)

---

### Вариант 2 (если сайт НЕ на WordPress, есть возможность разработки) — **OuterCom**

Если вы готовы написать/настроить серверную часть сами — OuterCom даёт максимальный контроль:

| Аспект | Оценка |
|--------|--------|
| Сложность установки | 🟡 Средняя (нужен Next.js, Postgres) |
| Гибкость | 🟢 Абсолютная |
| AI | 🟢 Claude или локальная LLM |
| Контроль данных | 🟢 Полный (MIT, сам себе хост) |
| Сообщество | 🔴 Очень маленькое (новый проект) |

---

### Вариант 3 (минимальный старт) — **Intergram**

Если нужно "прямо сейчас и бесплатно" — можно начать с Intergram:
- 2 строчки кода
- Бесплатный хостинг (или self-hosted)
- Базовые автоответы

Но потом упрётесь в отсутствие топиков/комнат — посетители будут пересекаться в одном чате.

---

### Вариант 4 (быстрый старт без Open Source) — **TGLiveChat**

Единственное НЕ open-source решение в списке, но:
- Даёт всё "из коробки"
- Бесплатный тариф
- Именно та архитектура, которую вы описали
- Если через пару месяцев захочется уйти — можно мигрировать
